# Machine Learning Module

## Student 4 - Machine Learning Engineer

This module contains the Machine Learning component of the AI-Based Phishing Email Detection and Analysis System.

The ML component is responsible for:

- Integrating NLP features with URL and Sender features.
- Training and comparing classification models.
- Selecting the final model.
- Generating phishing predictions.
- Producing a phishing probability / risk score.
- Preparing ML output for Backend integration.

5. TF-IDF Configuration

The final TF-IDF vectorizer configuration is:

TfidfVectorizer(
    max_features=10000,
    ngram_range=(1, 2),
    min_df=3,
    max_df=0.9,
    sublinear_tf=True
)

The vectorizer is fitted only on the training dataset.

X_train_tfidf = tfidf.fit_transform(train_text)
X_test_tfidf = tfidf.transform(test_text)

This prevents data leakage from the test dataset.

10. Final Model

The selected model is:

Calibrated Linear SVC

Linear SVC produced strong classification performance, but standard Linear SVC does not provide predict_proba().

Therefore, the classifier was calibrated using:

CalibratedClassifierCV

This allows the system to produce a phishing probability that can be presented as a risk score.

13. Backend Integration

For Backend integration, the ML module provides:

predict_from_analysis(...)

The Backend first calls the URL/Sender analysis function:

url_result = analyze_single_email(
    sender,
    body,
)

Then the result is passed to the ML component:

result = predict_from_analysis(
    sender=sender,
    subject=subject,
    body=body,
    url_analysis_result=url_result,
)

The final result contains:

label
prediction
risk_score
phishing_probability
risk_indicators
indicator_count
sender_domain
extracted_urls
domain_mismatch

Example:

{

    "risk_score": 65.95,
    "phishing_probability": 0.6594,
